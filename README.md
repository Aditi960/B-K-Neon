# B-K Neon

A modern and responsive business website for **B-K Neon**, focused on showcasing neon and LED board services with a clean UI, smooth user experience, and strong visual branding.

## 🚀 Overview

B-K Neon is a frontend web project designed to represent a neon/LED signage business online. The website highlights services, branding, contact details, and business presence through a visually engaging interface.

This project was built to improve:

* Online visibility for the business
* Customer engagement
* Professional branding
* Mobile accessibility

---

## ✨ Features

* Responsive design for desktop and mobile
* Modern neon-inspired UI
* Smooth scrolling and clean layout
* Service showcase sections
* Contact section for customer inquiries
* Fast-loading frontend architecture
* Beginner-friendly project structure

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Aditi960/B-K-Neon.git
```

Navigate into the project folder:

```bash
cd B-K-Neon
```

Open `index.html` in your browser.
